📖 Setup Instructions

Option 1: Netlify Forms (Recommended for beginners)

✅ Already working! Your submissions go to your Netlify Dashboard.

1. Submit a photo above

2. Check: Site Settings → Forms

3. View submissions there

Option 2: Cloudinary Setup

1. Create free account at cloudinary.com

2. Get your CLOUDINARY_NAME & CLOUDINARY_PRESET

3. Add to Netlify environment variables

4. Deploy and test

Option 3: Netlify Functions

1. Deploy the serverless functions (in your repo)

2. Configure S3 bucket or similar storage

3. Use the API endpoints
